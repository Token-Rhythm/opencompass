# PolyMath vendored LaTeX parser

These generated parser files and `latex2sympy2.py` are copied from
`QwenLM/PolyMath` commit
`fbf4e41cae78687d6be7447dbea897357c06aaa7`, directory
`eval/bundled/latex2sympy2`. Trailing whitespace was removed; executable
content is unchanged.

The upstream PolyMath repository is distributed under the Apache License 2.0.
Its parser README says the implementation was adapted from
<https://github.com/OrangeX4/latex2sympy> and regenerated for ANTLR 4.11.
Only the Python files required at runtime are vendored here.
